# 🚀 **Project Showcase: Inverted Search Using Hashing in C**

I'm excited to share my **Inverted Search project**, developed using C programming, hash tables, and linked lists! 💻

🔹 **Project Overview:**
This project purpose is to search for a word in multiple files  and display the files in which the word is present. The project uses a hash table to store the words from the files and a linked list to store the file names. 

✨ **Key Features:**
✅ Create a database from text files
✅ Display the indexed word database
✅ Search for specific words efficiently
✅ Track file names and word occurrence counts
✅ Save the database for future use
✅ Update the database with additional files

🛠️ **Technologies & Concepts:**
• C Programming
• Data Structures and Algorithms
• Hash Tables
• Linked Lists
• File Handling
• String Processing
• Dynamic Memory Allocation

🎯 **Key Learning:**
This project strengthened my understanding of hashing, linked-list operations, file handling, and efficient word indexing and searching.
